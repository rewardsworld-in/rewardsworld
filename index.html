05The tool and the learning path

A working tool sits behind every piece of work

You do not get a deck and a folder. The work is done in one workspace, so HR, finance and the board see the same numbers.

  1. 1Get data
  2. 2Check
  3. 3Build
  4. 4Review
  5. 5Deliver

Every service follows the same five steps. The files are checked before any number is used.

  • Data checked first

    Simple Excel templates explain every column. We check the files before any number is used.

  • Approvals on record

    Each review is approved by a different named person, and every decision is recorded.

  • Board summary and packs

    Excel, PowerPoint and print versions, each with a version stamp and the name of who approved it.

  • Rules with a source

    Legal figures are kept as dated rules, with the source, and updated on a simple screen.
